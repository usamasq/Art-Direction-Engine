# Examples

A complete fictional brand, taken end-to-end through the Art Direction Engine. Everything here is **invented for teaching** — no real client work lives in this repo.

## Ember & Comb — craft chili honey

A made-up small-batch hot-honey brand whose territory is **heat × comfort**: hearth-warm light and glossy amber, with the ember-red of the chili as the thing that interrupts the cosiness. It's deliberately not a generic "rustic foodie" look — see how the Profile earns every choice.

| [profile_EmberAndComb.md](profile_EmberAndComb.md) | A **fully filled Profile** (Doc 01), preceded by the **Creation-Guide rationale** (Doc 01A) that produced it — the territory, why it beats the generic option, the signature device. |
| [worked_reel_EmberAndComb.md](worked_reel_EmberAndComb.md) | A **full runnable video deliverable** ("The Drizzle" reel) built from that Profile — the stills-first loop laid out so a non-technical operator can run it top-to-bottom. |

## How to use these

- **Reading order:** the Profile first (the look), then the reel (the look in action).
- **As a template:** copy the Profile's structure for your own brand, then copy the reel's *format* for any multi-beat product video. The reel's closing section explains why the layout is the standard.
- **As an LLM reference:** drop the Profile into an assistant alongside the toolset docs to show it a concrete, correct target.

Want to see the rendered images that go with the reel? See [`../assets/`](../assets/) for the slots — render them yourself from the prompts in the worked example and drop them in.
